# NAGUIT PORTFOLIO

NAGUIT PORTFOLIO is a personal web-based portfolio built using the Laravel framework. This project presents a collection of my academic and personal projects as a Computer Science student, showcasing my skills, creativity, and continuous learning in web development and software technologies.


## 🚀 About the Project

This portfolio serves as a centralized platform to highlight my profile, achievements, skills, and projects. It demonstrates my understanding of backend development using Laravel, frontend design with Blade and Bootstrap, and database integration using MySQL.


## ✨ Features

- Portfolio Profile – Displays personal information and background  
- **Achievements** – Highlights academic and personal accomplishments  
- **Skills Section** – Showcases technical and professional skills  
- **Projects** – Presents academic and personal development projects  
- **Contact Form** – Allows visitors to send inquiries or messages  

## 🛠 Tech Stack

**Backend**
- Laravel 12  
- PHP  

**Frontend**
- PHP Blade 
- Bootstrap  
- HTML 
- CSS

**Database**
- MySQL
